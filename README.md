Entry for the [Monday Morning Punchlines](https://make.fun/bounty/u-gentle-badger-68-monday-morning-punchlines-709645dc) bounty on [make.fun](https://make.fun).

`main.ts` writes one joke about Monday mornings (at most 200 characters) to `/output/entry.txt`, deterministically — the same bytes on every run.

## Run

```sh
node main.ts
cat /output/entry.txt
```

## Entry

> I set five alarms for Monday morning. They formed a union and went on strike.
